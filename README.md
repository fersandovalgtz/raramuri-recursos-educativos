# Rarámuri · recursos educativos

Repositorio pedagógico complementario a [Rarámuri Digital](https://github.com/fersandovalgtz/raramuri-digital).

## Propósito

Separar la infraestructura lexicográfica y de datos de Rarámuri Digital de una capa específicamente educativa: materiales para enseñanza y aprendizaje, actividades, cuadernos, recursos visuales y otros productos pedagógicos que puedan reutilizarse con documentación y atribución claras.

## Relación con Rarámuri Digital

`raramuri-digital` seguirá siendo la fuente principal para datos lexicográficos, API, formatos interoperables, metadatos y documentación científica. Este repositorio alojará únicamente productos pedagógicos derivados o complementarios.

## Estructura prevista

- `cuadernos/`
- `actividades/`
- `vocabulario/`
- `recursos-visuales/`
- `docentes/`
- `documentacion/`

## Gobernanza y límites

La publicación de materiales relacionados con lengua y cultura rarámuri debe conservar procedencia, atribución y contexto. La disponibilidad técnica de un recurso no sustituye la validación lingüística ni la autoridad de las comunidades y personas hablantes.

No se publicarán materiales de terceros sin permiso ni contenidos culturalmente sensibles cuya difusión no esté claramente autorizada.
