# Lista de revisión antes de publicar

## Fuente

- [ ] El vocabulario/contenido tiene fuente identificada.
- [ ] Se registró versión o fecha de consulta.
- [ ] Las discrepancias con la fuente están explicadas.

## Pedagogía

- [ ] El objetivo de aprendizaje es claro.
- [ ] La actividad practica realmente ese objetivo.
- [ ] Existe una forma razonable de verificar aprendizaje.
- [ ] La dificultad es apropiada para la audiencia declarada.
- [ ] La gamificación, si existe, no oculta el contenido lingüístico.

## Variación y lengua

- [ ] Se documentó variante/contexto o se indicó `unknown`.
- [ ] No se presentó una variante como norma universal sin evidencia.
- [ ] El estado de revisión lingüística está visible.

## Cultura

- [ ] El recurso evita estereotipos y folclorización.
- [ ] Se revisó sensibilidad cultural.
- [ ] El contenido no requiere restricción comunitaria o ceremonial.

## Derechos

- [ ] Autoría y contribuciones están acreditadas.
- [ ] Texto, imágenes y audio tienen condiciones de uso claras.
- [ ] Los materiales institucionales conservan sus derechos.

## Accesibilidad

- [ ] Existe alternativa de bajo ancho de banda cuando sea viable.
- [ ] Las imágenes informativas tienen texto alternativo.
- [ ] El recurso no depende innecesariamente de una única modalidad.

## Publicación

- [ ] Tiene versión.
- [ ] Tiene changelog cuando corresponde.
- [ ] Tiene forma sugerida de cita.
- [ ] El estado de validación coincide con la evidencia real.
