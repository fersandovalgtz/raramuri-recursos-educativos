# Gobernanza de recursos educativos rarámuri

Este repositorio complementa a Rarámuri Digital desde una finalidad pedagógica. La apertura técnica no equivale a validación lingüística o cultural.

## Principios

### Procedencia

Cada recurso deberá indicar de dónde provienen vocabulario, ejemplos, imágenes, audios y referencias culturales.

### Atribución

La autoría y las contribuciones deberán conservarse de forma visible. Los materiales de terceros no se incorporarán como propios.

### Validación

Cuando un recurso dependa de decisiones lingüísticas o culturales, deberá distinguirse entre versión de trabajo, revisión técnica y validación por personas hablantes o instancias comunitarias pertinentes.

### Sensibilidad cultural

No se publicarán materiales cuya difusión pueda resultar improcedente por su carácter ceremonial, comunitario, personal o culturalmente restringido.

### Separación de capas

Los datos lexicográficos, API y formatos interoperables permanecen en `raramuri-digital`. Este repositorio concentra productos pedagógicos y documentación de uso educativo.

## Correcciones

Las observaciones lingüísticas o culturales deberán registrarse con procedencia y contexto suficiente para conservar trazabilidad entre versiones.
