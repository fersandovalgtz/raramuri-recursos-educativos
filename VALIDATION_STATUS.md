# Estados de validación

Cada unidad pedagógica debe mostrar un estado visible.

## `draft`

Versión de trabajo; puede contener decisiones pendientes y no debe usarse como referencia normativa.

## `source-checked`

Se verificó correspondencia con la fuente documental o con Rarámuri Digital, pero no implica revisión lingüística por hablantes.

## `technical-reviewed`

Se revisaron estructura, metadatos, accesibilidad, enlaces y coherencia pedagógica.

## `speaker-reviewed`

Una o más personas hablantes revisaron el contenido lingüístico. Debe registrarse variante/contexto, alcance de la revisión y consentimiento para acreditar la contribución cuando corresponda.

## `community-reviewed`

Hubo un proceso explícito de revisión o acuerdo con instancia/personas comunitarias pertinentes para el recurso y su contexto. No se utiliza esta etiqueta de forma genérica ni por una consulta aislada.

## `published`

El recurso pasó las revisiones definidas para su tipo y declara claramente sus límites.

## Importante

Un recurso `speaker-reviewed` no se presenta como válido para todas las variantes. La validación es situada y debe documentar quién revisó, qué se revisó y qué quedó fuera del alcance.
