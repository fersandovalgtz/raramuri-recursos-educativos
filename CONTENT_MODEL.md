# Modelo de contenidos pedagógicos

## Tipos de recurso

- ficha de vocabulario;
- actividad de relación o clasificación;
- secuencia didáctica;
- cuaderno imprimible;
- recurso visual;
- audio/pronunciación;
- lectura breve;
- juego o actividad gamificada;
- guía para docentes;
- microcurso.

## Metadatos mínimos

| Campo | Descripción |
|---|---|
| `resource_id` | Identificador estable. |
| `title` | Título. |
| `resource_type` | Tipo de recurso. |
| `learning_goal` | Propósito lingüístico/cultural. |
| `audience` | Población sugerida. |
| `level` | inicial, intermedio u otro criterio documentado. |
| `source` | Fuente del vocabulario o contenido. |
| `source_version` | Versión/fecha de consulta. |
| `variant_context` | Variante o contexto territorial conocido; `unknown` si no está documentado. |
| `authors` | Autoría pedagógica. |
| `contributors` | Hablantes, revisores, ilustradores u otras contribuciones. |
| `validation_status` | Estado según VALIDATION_STATUS.md. |
| `sensitivity` | open, review-required, restricted. |
| `license` | Licencia aplicable al recurso específico. |
| `rights_notes` | Restricciones o materiales de terceros. |
| `accessibility` | Formatos y apoyos disponibles. |
| `version` | Versión del recurso. |
| `reviewed_at` | Fecha de última revisión. |

No se rellenan campos lingüísticos desconocidos por inferencia automática. La ausencia de información se documenta como ausencia.
