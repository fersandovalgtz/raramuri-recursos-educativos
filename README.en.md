# Rarámuri · educational resources

Open pedagogical infrastructure complementary to [Rarámuri Digital](https://github.com/fersandovalgtz/raramuri-digital). It supports educational materials whose provenance, linguistic variation, validation status, and cultural-safety constraints can be documented explicitly.

## Purpose

Rarámuri Digital maintains the lexicographic research layer. This repository develops the pedagogical layer: activities, workbooks, learning sequences, educational vocabularies, visual resources, and—when appropriate permissions exist—audio and pronunciation materials.

The separation is deliberate: technical availability of a lexical form does not make it a pedagogically, linguistically, or culturally validated teaching choice.

## Validation model

```text
draft
  ↓
source-checked
  ↓
technical-reviewed
  ↓
speaker-reviewed        ← only when this review occurred
  ↓
community-reviewed      ← only when this process occurred
  ↓
published
```

A review by one speaker is not represented as authority for every Rarámuri variety. Each review should retain its actual scope and provenance. See [`VALIDATION_STATUS.md`](VALIDATION_STATUS.md), [`REVIEW_WORKFLOW.md`](REVIEW_WORKFLOW.md), and [`PROVENANCE.md`](PROVENANCE.md).

## Scientific and ethical framework

The repository combines reproducible research-software practices with safeguards appropriate to educational resources linked to a living Indigenous language. Its core documentation includes:

- [`PEDAGOGICAL_FRAMEWORK.md`](PEDAGOGICAL_FRAMEWORK.md)
- [`GOVERNANCE.md`](GOVERNANCE.md)
- [`PROVENANCE.md`](PROVENANCE.md)
- [`FAIR_ASSESSMENT.md`](FAIR_ASSESSMENT.md)
- [`SCIENTIFIC_REPOSITORY_STANDARD.md`](SCIENTIFIC_REPOSITORY_STANDARD.md)
- [`VARIATION_POLICY.md`](VARIATION_POLICY.md)
- [`CULTURAL_SAFETY.md`](CULTURAL_SAFETY.md)
- [`AUDIO_POLICY.md`](AUDIO_POLICY.md)
- [`LICENSE_STRATEGY.md`](LICENSE_STRATEGY.md)

FAIR/FAIR4RS is treated as a technical and scholarly framework, not as a substitute for authority, consent, responsibility, benefit, or ethics. No external FAIR certification or comprehensive community validation is claimed.

## Status

**Infrastructure version 0.2.0 · August 2026.** The current phase publishes frameworks, inventories, and review workflows. Linguistic content is not represented as exhaustively or uniformly validated across all territorial varieties.
