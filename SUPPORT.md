# Soporte, correcciones y contribuciones

Utilice issues para proponer correcciones de metadatos, señalar variantes, discutir diseño pedagógico, reportar enlaces rotos o proponer nuevos recursos.

Las observaciones lingüísticas deben indicar, cuando sea posible, fuente, variante o contexto. No se consideran autoridad suficiente las traducciones o normalizaciones generadas automáticamente por IA.

Para asuntos que involucren consentimiento, audio, material cultural sensible o información no publicable, contacte al responsable de forma privada y no adjunte el contenido restringido a GitHub.
