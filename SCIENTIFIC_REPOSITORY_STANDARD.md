# Estándar científico y pedagógico del repositorio

Este documento define el estándar mínimo para publicar y mantener **Rarámuri · recursos educativos** como infraestructura académica abierta vinculada con una lengua indígena viva.

## 1. Metadatos y citación

El repositorio debe mantener coherentes `CITATION.cff`, `codemeta.json`, versión, licencia, README y changelog. Un DOI sólo se incorpora después de un depósito real y verificable.

## 2. Procedencia

Todo recurso debe conservar, según corresponda, fuente, autoría, variante, contexto, transformaciones, estado de revisión y licencia. La transformación pedagógica no elimina la dependencia con la fuente lingüística o documental.

## 3. Estados de validación

Los estados `draft`, `source-checked`, `technical-reviewed`, `speaker-reviewed`, `community-reviewed` y `published` son distintos. Ninguno se asigna por inferencia ni por conveniencia editorial.

## 4. Variación y autoridad

Una revisión situada no autoriza generalizaciones sobre todas las variantes rarámuri. El repositorio debe comunicar con precisión quién revisó, qué se revisó y cuál es el alcance de esa revisión, preservando privacidad cuando corresponda.

## 5. Seguridad cultural y consentimiento

La apertura técnica está subordinada a condiciones de atribución, consentimiento y pertinencia cultural. Audio, imágenes, relatos y contenidos culturalmente sensibles requieren controles específicos antes de publicación.

## 6. FAIR / FAIR4RS y CARE

La infraestructura debe maximizar descubribilidad, acceso, interoperabilidad y reutilización sin convertir FAIR en argumento para ignorar autoridad, beneficio, responsabilidad o ética. `FAIR_ASSESSMENT.md` documenta el estado y las brechas del proyecto.

## 7. Reproducibilidad

Los catálogos, validaciones automáticas y transformaciones deben ser versionables y, cuando corresponda, regenerables mediante workflows o scripts documentados. Una release estable debe congelar sus metadatos y artefactos esenciales.

## 8. Comunicación pública

El README debe permitir distinguir inmediatamente propósito, estado, fuentes, validación, derechos y relación con Rarámuri Digital. No se usarán badges o afirmaciones de certificación que excedan la evidencia disponible.

## 9. Integridad de enlaces

Los enlaces institucionales, académicos, DOI y repositorios relacionados deben verificarse periódicamente. Los recursos inexistentes, migrados o privados no deben permanecer como rutas principales de navegación.
