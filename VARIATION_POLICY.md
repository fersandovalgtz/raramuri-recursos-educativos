# Política de variación lingüística

El repositorio no presupone una forma única, homogénea o territorialmente universal del rarámuri.

## Principios

### Registrar antes que normalizar

Cuando dos formas difieren, se conservan como variantes documentadas antes de decidir si existe error, diferencia ortográfica, variación dialectal o uso contextual.

### Contexto de variante

Cada recurso debe incluir `variant_context` cuando sea conocido: región, comunidad, fuente, persona revisora u otro contexto pertinente. Si no existe información suficiente, se utiliza `unknown`; no se infiere automáticamente.

### Forma pedagógica y forma fuente

Una decisión para simplificar una actividad inicial debe distinguirse del registro lingüístico de origen. El recurso educativo no modifica silenciosamente la fuente lexicográfica.

### Desacuerdos

Las revisiones contradictorias pueden coexistir documentadas. No se elimina una variante solo para producir consistencia visual.

### Búsqueda y equivalencia

Las interfaces futuras pueden relacionar variantes para facilitar búsqueda, pero una relación computacional de equivalencia no debe presentarse como identidad lingüística absoluta.

## IA y normalización

Los modelos de lenguaje no se utilizan como autoridad para decidir qué variante es correcta. Pueden sugerir coincidencias o detectar inconsistencias para revisión humana, pero la decisión final debe conservar fuente y contexto.
