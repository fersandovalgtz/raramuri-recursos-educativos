# Contribuciones

Las contribuciones lingüísticas y culturales requieren más información que una corrección de software ordinaria.

## Para una corrección lingüística

Indique palabra/expresión, forma actual, propuesta, fuente o experiencia que sustenta la observación, variante/contexto conocido y si autoriza que su nombre aparezca en créditos.

## Para un recurso pedagógico

Incluya objetivo, audiencia, fuente, autoría, licencia, estado de validación, notas de accesibilidad y materiales editables cuando existan.

## Para audio

No se acepta audio de terceros sin consentimiento verificable. Debe registrarse persona o código de contribuyente, contexto/variante, permiso de publicación y licencia o condiciones de reutilización.

## Uso de IA

La IA puede apoyar maquetación, código o generación de borradores, pero no se considera fuente lingüística. Ninguna forma rarámuri generada o corregida automáticamente se incorpora como validada sin revisión humana pertinente.

## Trato de desacuerdos

Las variantes y discrepancias se documentan. El objetivo no es forzar una única forma cuando la diversidad sea lingüísticamente real.
